Datenschutz

Diese Hinweise beschreiben, welche Daten beim Besuch dieses Portfolios technisch verarbeitet werden.

Daniel Brodbeck

Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Beim Aufruf können technisch notwendige Verbindungsdaten, insbesondere die IP-Adresse, Zeitpunkt, angeforderte Datei, Browsertyp und Betriebssystem, durch den Hostinganbieter verarbeitet und in Serverprotokollen gespeichert werden.

Weitere Informationen finden Sie in der Datenschutzerklärung von GitHub.

Kontaktaufnahme

Wenn Sie per E-Mail Kontakt aufnehmen, werden die von Ihnen übermittelten Angaben zur Bearbeitung Ihrer Anfrage verwendet. Die Website selbst enthält kein Kontaktformular und speichert keine Kontaktdaten.

Instagram

Die Website enthält einen einfachen Link zu Instagram. Beim blossen Besuch dieses Portfolios werden keine Instagram-Inhalte eingebettet oder geladen. Erst beim Öffnen des Links gelten die Bedingungen des externen Anbieters.

Google Analytics

Google Analytics ist derzeit nicht aktiviert. Dieses Portfolio lädt keine Analytics-Skripte und setzt keine Analyse-Cookies. Vor einer späteren Aktivierung werden diese Hinweise ergänzt und eine Einwilligungsmöglichkeit eingerichtet.

Ihre Anfrage zum Datenschutz

Fragen zur Bearbeitung Ihrer Daten können Sie an brodbeck@becknet.ch richten.
